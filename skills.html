Skills：把做法存起來

一件事你已經跟 Claude 做順了，就把做法寫成一份說明書。以後說一句「出題」，它就照說明書做，不用再教一次。

學完你會
  • 把一個做順的流程存成 Skill
  • 分得出 Skill、Project、Instructions 的差別
  • 開新對話測一次，確定它真的照做

阿糰 60 秒示範
Reel 準備中

先看阿糰怎麼把「講義出題」存成 Skill，再照下面三步自己做一次。

三步做出你的第一個 Skill

  1. 先在對話裡做順三次

    挑一件你每週都在做的事，例如上傳講義請它出題。照平常的方式跟它來回，做到結果滿意為止，重複三次。

  2. 請它把做法寫成說明書

    在同一個對話裡說：「把我們剛剛的做法寫成一個 Skill 的說明。」它會給你一段文字，裡面有名稱、什麼時候用、步驟。

    Claude 對話（示意）
    把我們剛剛的做法寫成一個 Skill 的說明
    Claude 回你：名稱｜什麼時候用｜步驟｜輸出格式

  3. 存進 Customize › Skills

    設定 → Customize → Skills → ＋ 新增，把那段文字貼進「內容」。也可以按「從對話建立」，它會幫你填好。

    設定 › Customize › Skills（示意）
    講義出題上傳講義說「出題」時用
    週報初稿每週五，從信件抓三個成果
    ＋ 新增 Skill從對話建立

現在就試

複製這段，貼給 Claude 
我每次上傳講義都會請你出題。請幫我寫一個 Skill 的說明：
名稱：講義出題
什麼時候用：我上傳講義並說「出題」
步驟：先列 10 條重點 → 出 15 題選擇題 → 一次給一題 → 錯的整理成觀念卡（問題｜答案｜頁碼）

做對的樣子：存好後開新對話，上傳講義說「出題」，回答上方會出現「使用 Skill 講義出題」。

三個很像的東西，怎麼分

  • Instructions你是誰、你的偏好。每個對話都會用到。
  • Project一個主題的背景和檔案。只在這個 Project 裡有效。
  • Skill一件事的做法。做那件事的時候才拿出來。

原則：一個 Skill 只做一件事。「做週報」是一個，「做週報順便整理行事曆」是兩個。

常見卡關

說了「出題」，它沒有用 Skill

檢查「什麼時候用」那格有沒有寫到你說的那句話。寫得越像你平常講的話，它越會判斷要用。

找不到 Customize

點左下角你的名字 → 設定，左側就有 Customize。手機 app 的位置可能不同，建議先用電腦設定。

Skill 和 Project 該用哪個？

要放檔案、背景資料，用 Project；要它記住「怎麼做」，用 Skill。兩個可以一起用。
